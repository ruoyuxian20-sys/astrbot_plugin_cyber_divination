# 赛博占卜 cyber_divination

一个 AstrBot v4 插件，提供四种传统占卜体系的娱乐实现：

- **周易六爻**：三枚铜钱起卦，输出本卦、卦辞、爻象与变卦
- **观音灵签**：一百签，含吉凶、签诗与解曰
- **塔罗牌**：单张指引或「过去 · 现在 · 未来」三张牌阵（大阿卡纳 22 张 + 小阿卡纳 56 张）
- **奇门遁甲**：简式时家排盘，输出四柱、用局、值符值使与九宫盘

所有功能仅在收到命令时响应，不会主动冒泡刷屏。

## 安装

把整个 `cyber_divination` 目录复制到 AstrBot 数据目录的 `data/plugins/` 下，然后在
Dashboard 启用插件（或重启 AstrBot）。

## 使用

默认唤醒前缀为 `/`：

```
/占卜 六爻 [所问之事]               例如 /占卜 六爻 明天适合出门吗
/占卜 灵签 [所问之事]               例如 /占卜 灵签 事业
/占卜 塔罗 [单张|三张] [所问之事]    例如 /占卜 塔罗 三张 感情
/占卜 奇门 [YYYY-MM-DD HH:MM] [所问之事]
                                   例如 /占卜 奇门 2026-08-01 15:30 出行吉凶
/占卜 帮助                         查看使用说明
```

英文命令 `/divine zhouyi` 等同理；子命令也支持中文别名（六爻、周易、灵签、塔罗、奇门等）。

## 配置（Dashboard 插件设置）

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `llm_enabled` | `false` | 是否启用 LLM 润色解读。开启后调用当前会话模型生成个性化解读 |
| `llm_cooldown_seconds` | `300` | 每个会话两次 LLM 调用的最小间隔（秒），防止频繁调用 |
| `llm_timeout_seconds` | `30` | 单次 LLM 调用超时（秒），超时自动回退内置解读 |
| `use_image` | `false` | 是否用图文卡片输出。需要 AstrBot 文本转图（T2I）可用，渲染失败自动回退纯文本 |

稳定性设计：LLM 调用全程带超时与异常保护，任何失败都会静默回退到内置资料库解读，
不会导致占卜无响应。

## 说明与免责

- 灵签签文为**民间通行整理版**，不同版本可能存在异文；周易卦辞取自通行文本。
- 奇门遁甲采用**简式时家排盘**：节气日期近似、未处理超接置闰，天盘/八门/八神按九宫
  数字序顺逆飞布（神盘不入中五），结果仅供娱乐参考。
- 本项目所有占卜内容仅供娱乐，不构成任何决策建议，请理性看待。

## 开发

核心逻辑位于 `core/`，均为纯 Python（无 astrbot 依赖），可独立测试：

```
python -m pytest cyber_divination/tests
ruff check cyber_divination
```
